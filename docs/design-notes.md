# offload visual direction

The identity is a lowercase, bold sans-serif wordmark with an open circle and outgoing arrow. The independent icon fits a rounded periwinkle tile. SVG assets are editable and scale without raster blur. The wordmark uses Arial/Helvetica fallback text, not fully outlined glyphs; outline it if a strict production brand master is needed.

The reference images supplied by the user inform white space, photographic fashion content, rounded panels and blue/periwinkle controls. Market inspiration reviewed:
- Vinted: https://www.vinted.com/about — approachable resale, clothes getting another life.
- Fleek: https://web.joinfleek.com/home — direct resale language and bold fashion marketplace presentation.
- Depop: https://www.depop.com/ — fashion-led circularity.
